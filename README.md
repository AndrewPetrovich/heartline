# HEARTLINE Novel Player — MVP

Мобильная PWA-читалка для интерактивных мини-новелл. В сборку уже встроена новелла **«Последняя подача»**, собранная из пяти DOCX из переданного архива.

## Что работает

- чтение в мобильном полноэкранном интерфейсе;
- сцены, диалоги, мысли и нарратив;
- `CHOICE / OPTION`;
- `SET / CLEAR`, числовые параметры и флаги;
- `IF`-условия (с эвристикой для литературного формата HEARTLINE без явного `ENDIF`);
- `GOTO` и маршрутные переходы;
- автоматический расчёт маршрута `HONESTY / ATTRACTION / TRUST` для текущей новеллы;
- три финальных маршрута;
- автосохранение прогресса в браузере;
- история прочитанного;
- debug-панель: сцена, переменные, флаги, технический контекст, быстрый переход к любой сцене;
- экспорт текущего состояния и разобранной новеллы в JSON;
- импорт одного/нескольких `.docx` или `.zip` с DOCX;
- офлайн-режим после установки как PWA.

## Критическое правило импорта

Для каждого DOCX читается `word/styles.xml`, стиль каждого абзаца сопоставляется с его настоящим именем. Если имя стиля **начинается с `НЕ ЭКСПОРТИРОВАТЬ`**, абзац целиком исключается до построения сцен и ветвлений.

В переданном наборе при подготовке встроенной версии было исключено **184** таких абзаца. В игру вошло **52 сцены** и **17 выборов**.

## Как запустить

### Быстрая локальная проверка

В папке проекта:

```bash
python -m http.server 8080
```

После этого открыть на компьютере `http://localhost:8080`.

Чтобы проверить на телефоне в одной Wi-Fi сети, открыть IP компьютера с портом `8080` (например, `http://192.168.1.20:8080`). Для полноценной установки PWA на телефон лучше разместить папку на любом статическом HTTPS-хостинге.

### Размещение

Проект не требует сборки, npm или backend. Достаточно опубликовать содержимое папки как статический сайт (GitHub Pages, Cloudflare Pages, Netlify, Vercel или свой HTTPS-сервер).

## Формат DOCX

Текущий импортёр распознаёт стили:

- `Heading 1` с заголовком вида `[SCENE_ID] Название сцены`;
- `Scenario Narration`;
- `Scenario Thought`;
- `Scenario Dialogue` — ожидается `SPEAKER` + минимум два пробела + текст;
- `Scenario Tech`.

Поддержанные команды `Scenario Tech`:

`BG`, `CG`, `MUSIC`, `SFX`, `SPRITE`, `REACTION`, `FADE`, `SET`, `CLEAR`, `IF`, `SYSTEM`, `GOTO`, `CHOICE`, `OPTION`.

## Важная оговорка MVP

В сценариях HEARTLINE условные блоки записаны через `IF:` без явного `ENDIF`, а в некоторых двухвариантных выборах общий хвост сцены помещён после последнего `OPTION`. MVP применяет безопасные эвристики для этого формата. Для полностью формального импорта будущих новелл рекомендуется позже добавить `ENDIF` и `ENDCHOICE`/`ENDOPTION` в технический слой сценария — литературный текст при этом менять не потребуется.
