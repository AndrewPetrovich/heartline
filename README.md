# HEARTLINE Novel Player — Literary v3 Rebuild

Мобильная PWA-читалка для интерактивных мини-новелл. Во встроенную сборку включена **«Последняя подача»**, пересобранная по пяти томам **«Литературной редакции 3.0»**.

## Сценарная сборка

Источники встроенной версии:

1. `08_01_Сценарий_Главы_1–2_литературная_редакция.docx`
2. `08_02_Сценарий_Главы_3–4_литературная_редакция.docx`
3. `08_03_Сценарий_Главы_5–6_литературная_редакция.docx`
4. `08_04_Сценарий_До_рассвета_и_утро_литературная_редакция.docx`
5. `08_05_Сценарий_эпилоги_литературная_редакция.docx`

В сборке: **52 сцены**, **17 интерактивных выборов**, три маршрута (`ROUTE_EQUAL`, `ROUTE_FIRE`, `ROUTE_MASK`) и три эпилога.

## Что изменено в этой пересборке

- встроенный `novel.json` и `builtin-novel.js` заменены текстом литературной редакции 3.0;
- сохранены утверждённые `Scene_ID`, `Choice_ID`, `Option_ID`, `Flag_ID` и `Route_ID`;
- общий хвост двухвариантных выборов в сценах кульминации/утра нормализован, чтобы обе опции продолжали сцену корректно;
- для неоднозначных `IF` без `ENDIF` во встроенной новелле записана точная длина условного блока; плеер умеет использовать её вместо эвристики;
- добавлена `contentVersion`: старый локальный прогресс предыдущей встроенной редакции не будет продолжен поверх нового текста;
- PWA-кэш поднят до `heartline-reader-v3`, чтобы браузер не держал старый `builtin-novel.js`.

## Возможности плеера

- сцены, диалоги, внутренние мысли и нарратив;
- `CHOICE / OPTION`;
- `SET / CLEAR`, числовые параметры и флаги;
- `IF`, `GOTO`, маршрутные переходы;
- расчёт маршрута по `HONESTY / ATTRACTION / TRUST`;
- автосохранение, история и debug-панель;
- экспорт состояния и JSON;
- импорт `.docx` / `.zip` с DOCX;
- PWA и офлайн-кэш.

## Запуск

Локально:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

Для GitHub Pages публикуйте **содержимое этой папки в корень репозитория**. `index.html` должен лежать на верхнем уровне.

## Примечание об импортере DOCX

Текущий импортёр распознаёт стили `Heading 1`, `Scenario Narration`, `Scenario Thought`, `Scenario Dialogue`, `Scenario Tech` и исключает абзацы, стиль которых начинается с `НЕ ЭКСПОРТИРОВАТЬ`.

Во встроенной версии этой сборки неоднозначные границы `IF` и общие хвосты выборов уже нормализованы. При импорте произвольных будущих DOCX без явных `ENDIF` / `ENDOPTION` по-прежнему используются эвристики, поэтому для нового производственного стандарта лучше добавить явные технические маркеры окончания блоков.
