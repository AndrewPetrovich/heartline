HEARTLINE Editor v3.0.4 — Horizontal Chapters + Moon Oath

Что изменено
1. В режиме «Граф → Структура» главы расположены вертикальным списком,
   а сцены ВНУТРИ каждой главы идут слева направо.
2. Локальные развилки уходят вверх/вниз от горизонтальной линии; длинные
   переходы между главами проходят по внешнему краю ряда.
3. Сохранены режимы «Маршруты» и «Схема».
4. Добавлена вторая встроенная новелла «Лунная клятва» (proofreading-v4).
5. «Лунная клятва» не заменяет и не сбрасывает «Последнюю подачу».
6. Для inline-choice добавлено продолжение чтения в той же сцене и
   поддержка строковых условий/условных вариантов.

Обновление
Загрузите все файлы из UPDATE-архива в корень репозитория и подтвердите
замену существующих файлов. Затем один раз откройте upgrade-v304.html.

Данные IndexedDB не очищаются.
