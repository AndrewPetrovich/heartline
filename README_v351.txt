HEARTLINE Editor 3.5.1 — Unified Reader + Proofreading
=====================================================

Изменено по сравнению с 3.5.0:

- вкладка «Читать» скрыта; чтение и вычитка объединены;
- legacy-переходы в Reader автоматически открывают «Вычитку»;
- навигация: Первая / Назад / Вперёд / Последняя;
- «Вперёд» автоматически отмечает текущий fragmentId вычитанным;
- открытое замечание не блокирует переход, но не позволяет поставить reviewed;
- отдельные проходы вычитки удалены;
- formatVersion proofreading state = 2; старые pass-records мигрируют автоматически;
- Reader preferences перенесены в «Вычитку»: контекст, шрифт, размер, интерлиньяж, ширина, focus;
- добавлен раздел «Стиль и качество»;
- добавлен показатель «Редакционная готовность» вместо субъективного quality score;
- добавлен редакторский style guide проекта;
- Choice options отображаются рядом с проверяемым prompt;
- мобильный Сториборд снова остаётся в основной навигации, потому что отдельной кнопки «Читать» больше нет.

Сохранены durable anchors, словарь, локальные проверки, safe search/replace,
route coverage, Project Core recovery/conflict protection и granular reviewedHash.
