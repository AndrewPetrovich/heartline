HEARTLINE Editor v3.0.3 — Graph Views

Раздел «Граф» теперь имеет три представления в существующем дизайне HEARTLINE:

1. СТРУКТУРА — основной рабочий интерфейс
   - полный Outline сцен и решений слева;
   - ключевые сюжетные узлы в центре;
   - Inspector справа;
   - minimap в нижнем левом углу холста;
   - линейные сцены сворачиваются в связи «N сцен».

2. МАРШРУТЫ — анализ ветвлений
   - широкие цветные потоки маршрутов;
   - главы как вертикальные временные уровни;
   - ключевые сцены/решения поверх потоков;
   - отдельные дорожки «На равных», «Игра с огнём», «Без масок», «Прямой маршрут».

3. СХЕМА — сверхкомпактный Metro map
   - одна линия = маршрут;
   - станции = главы/группы сцен;
   - маленькие точки показывают количество сцен;
   - концовки вынесены вправо;
   - удобен для оценки всей новеллы на одном экране.

Во всех режимах:
- поиск;
- фильтры;
- колесо мыши — zoom к курсору;
- средняя кнопка мыши или Space+drag — перемещение;
- двойной клик открывает сцену;
- Inspector показывает входы/выходы и варианты Choice.
