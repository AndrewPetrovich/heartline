HEARTLINE Editor 3.5.2 — Typography Cleanup
===========================================

Изменения интерфейса
--------------------
- удалена отдельная кнопка «Проверить текст» под редактором;
- правая панель больше не содержит вкладки «Проверки/Качество» и «Словарь»;
- правая панель показывает один контекст: «Замечания» либо «Стиль и качество»;
- словарь проекта остаётся совместимым на уровне данных, но не показывается как отдельная вкладка.

Типографика
-----------
Во всём пользовательском интерфейсе запрещены bold / extra-bold начертания.

Политика:
- обычный текст: 400;
- максимальный акцент: 600 (semibold);
- веса 650/700/750/800/850 из legacy-модулей нейтрализуются финальным stylesheet;
- synthetic bold отключён.

Это относится к заголовкам, кнопкам, вкладкам, навигации, статусам, счётчикам и Graph/Reader/Proofreading UI.
