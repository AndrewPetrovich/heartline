HEARTLINE Editor 3.9 — Editorial Pipeline

Main workflow
-------------
1. Вычитка
2. Визуалы
3. Финальная проверка

Highlights
----------
• One workspace keeps the same fragment selected while changing editorial stage.
• Text stage keeps automatic save and "Next = reviewed".
• Visual stage uploads/replaces an image directly on the current fragment.
• Focal point can be moved directly on Preview; zoom/overlay remain editable.
• Final stage combines Preview, text editing, image replacement, reviews and readiness.
• "Final reviewed" is bound to both textHash and visualHash.
• Text/visual changes automatically make a previous final review stale.
• Final "Next" may re-confirm clean edited text before completing the frame.
• Project cards show Text / Visual / Final progress independently.
• Legacy Reader and Preview deep links open the unified workspace.
• Standalone Preview is removed from the Tools menu.
• Existing Preview Lab device profiles remain reusable in Final.
