HEARTLINE Editor 3.2.1 — Graph 2.0 Hardening

Обновление укрепляет реализацию Graph 2.0 без изменения IndexedDB.

Основные вкладки:
- Библиотека
- Читать
- Сториборд
- Граф

Инструменты:
- Изображения
- Превью
- Замечания
- GPT

Проект:
- Версии
- Экспорт

Четыре режима Graph:
1. Карта главы — только локальная структура текущей главы.
2. Карта решений — стратегические Choice, слияния, начало и финалы.
3. Анализ путей — Sankey-подобные потоки; толщина = сцены/кадры/слова.
4. Карта романа — радиальная карта глав и финалов.

Исправления Graph:
- metadata endings соединяются с фактическими финальными маршрутами;
- стратегические решения распределяются по всей истории;
- карты строятся по времени/главам, а не по случайному индексу массива;
- параллельные Choice-связи разводятся и не лежат друг на друге;
- промежуточные сцены сворачиваются в метрики на связи;
- hover изолирует только входящие/исходящие связи;
- Focus Path сохраняет предков и потомков выбранной сцены;
- pinch zoom на touch;
- pan: middle mouse / Space+drag / touch;
- F = fit, 0 = 100%, Esc = снять selection.
