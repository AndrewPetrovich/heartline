HEARTLINE Editor v3.0.2 — Story Map redesign

Что изменено:
- Карта по умолчанию больше не показывает все 52 сцены одновременно.
- Режим «Обзор структуры» показывает только ключевые сюжетные узлы: начало, первые сцены глав, развилки, входы в ветки, слияния, текущую сцену и концовки.
- Линейные последовательности сворачиваются в связи с подписью «N сцен».
- Главы располагаются слева направо отдельными колонками.
- Маршруты располагаются по горизонтальным дорожкам: Общая линия / На равных / Игра с огнём / Без масок / Прямой маршрут.
- Добавлен режим «Все сцены (подробно)» в выпадающий список карты.
- Поиск временно раскрывает найденную сцену даже в обзорном режиме.
- Фильтры «Непройденные», «Без изображений», «С замечаниями», «Концовки» показывают совпадения в контексте ключевой структуры.
- Текущая сцена, замечания, начало и концовки визуально различаются.
- Колесо мыши масштабирует к курсору; средняя кнопка мыши или Space+drag перемещают холст.
- При открытии карта автоматически вписывается в доступную область.
